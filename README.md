# Ellamara Store

Tema y plugins propios de [Ellamara](https://ellamarastore.com/), una tienda WordPress con WooCommerce.

1. [Modificar código, crear un PR y hacer merge a main](docs/codigo/README.md)
2. [Administrar y sincronizar productos, fotos y categorías en WooCommerce](docs/woocommerce/README.md)

El código del tema vive en `wp-content/themes/ellamara`. Los plugins propios están en `wp-content/plugins/ellamara-*`. Los productos, imágenes, pedidos y ajustes de WordPress se administran desde el panel del entorno correspondiente.
